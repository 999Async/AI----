# 联调作业

`homework-test.png` 是用 Pillow 排版的人工测试图片，不含真实学生信息。

1. Simplify: 3(x + 2) - x；预设学生原答 2x + 2。应判错，正确化简为 2x + 6。
2. Solve: 2x + 3 = 11；预设学生原答 x = 4。应判对。

这两题用于验证图片确实传入模型，以及结果、对话、订正和记忆的传输链路，不能代表 OCR 或数学批改质量评估。
