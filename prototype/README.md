# 伴学产品原型

在 macOS 上首次安装本机守护服务：

```sh
python3 scripts/banxue_service.py install
```

安装后访问 <http://127.0.0.1:4178>。服务会在登录后自动启动，异常退出后由 `launchd` 自动拉起；页面每 20 秒做一次健康检查，断线时使用退避重连。即使直接双击 `prototype/index.html`，也会自动转到受守护的 HTTP 地址。为避免 macOS 阻止后台进程读取 `Documents`，安装器会把运行副本和 SQLite 数据放在 `~/Library/Application Support/Banxue`；再次运行 `install` 即可同步项目更新。查看状态：

```sh
python3 scripts/banxue_service.py status
```

临时调试也可在项目根目录手动运行：

```sh
python3 backend/server.py --port 4178
```

打开 <http://127.0.0.1:4178>。页面不提供模拟学习数据，也不会在真实服务失败时替换成固定题目。

## 当前流程

1. 上传自己的作业或题目图片。
2. Codex 识别题目、原答和知识点，并给出可核查的批改结果。
3. 学生按题订正，也可主动请求提示、例子或分析。进入对话后，模型会结合本题与已有学习上下文推荐相关问题；点击只填入输入框，学生修改并发送后才请求辅导。
   “一起想”可切换对话或画板；画板以当前题目初始化，学生落笔后才能主动请求模型查看。
4. 后端保存原答、讨论、帮助、订正和记忆依据。
5. 首页跨作业聚合同一知识点的重复信号，推荐一个短学习单元。
6. 学习单元用新例题讲方法，再给迁移题；不会把最近未完成题包装成推荐。

## 推荐资格

- 至少有 2 份真实作业、3 条题目记录。
- 同一知识点在至少 2 份作业中重复出现，并有至少 2 条待补强信号。
- 知识状态综合错答、帮助后完成和独立完成；思考模式来自服务端记忆中的有依据判断。
- 证据不足时只引导继续真实学习，不请求模型生成推荐。
- 推荐结果引用后端已保存的真实事件；引用不存在时拒绝采用。

## 当前边界

- 数据保存在本机浏览器与本机 SQLite，没有账号或跨设备同步。
- 画板是 P0 集成探针：复用 PenEcho `v1.3.1` 的 `draw` 命令与渲染模块，模型回复开放受约束的文字回复，以及仅在适用题目中启用的长方形旋转教学图。上游信息见 `vendor/penecho/UPSTREAM.md`。
- 学生笔迹和确认后的模型文字按题存在 IndexedDB；未确认的模型草稿也会恢复，但不视为学生作答。
- 旧记录若没有知识点字段，只从已保存题目与服务端记忆中重建分类。
- 推荐与批改由真实模型生成，但尚未做系统准确率评测。
- 当前迁移题用于呈现学习闭环，尚未接入作答提交与长期保持验证。
- 原型跑通不代表学习效果或业务价值已经得到验证。

自动检查：`PYTHONPATH=backend python3 -m unittest backend/test_gateway.py`，以及 `node prototype/*.test.cjs`（逐文件执行）。
